📌 Sobre o projeto

O AgroSaber é um projeto de tecnologia voltado ao setor agrícola, desenvolvido com o objetivo de demonstrar como ferramentas digitais podem facilitar o acompanhamento de plantações, a interpretação de indicadores e a organização de informações relacionadas às culturas.

A plataforma apresenta um painel interativo com indicadores, gráficos e registros agrícolas, permitindo visualizar informações de maneira organizada e intuitiva.

O projeto também prevê a evolução para recursos de Inteligência Artificial, com foco em auxiliar a interpretação dos dados e apoiar decisões no campo.

🎯 Objetivos

- Facilitar a visualização de informações agrícolas.
- Organizar dados de diferentes culturas.
- Acompanhar indicadores por meio de gráficos.
- Registrar informações e relatórios de plantações.
- Explorar o uso de Inteligência Artificial no apoio à tomada de decisões agrícolas.

🌾 Culturas demonstradas

A demonstração contempla quatro culturas:

Cultura| Identificação
🌾 Trigo| Acompanhamento de indicadores
🫘 Soja| Visualização de dados
🌱 Feijão| Registros agrícolas
🌾 Arroz| Análise demonstrativa

🤖 Inteligência Artificial — Evolução planejada

Uma das propostas de evolução do AgroSaber é incorporar Inteligência Artificial para auxiliar na interpretação dos dados agrícolas.

Entre as funcionalidades planejadas estão:

- Análise de informações das plantações.
- Identificação de possíveis inconsistências nos registros.
- Interpretação de indicadores agrícolas.
- Geração de relatórios inteligentes.
- Sugestões de manejo baseadas nos dados disponíveis.
- Comparação de informações entre períodos e culturas.

Importante: esses recursos de IA fazem parte do planejamento de evolução. A versão pública demonstrativa utiliza dados fictícios e não representa recomendações agronômicas reais.

🚀 Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo "index.html" no navegador.

git clone https://github.com/gabrielconceicao01/AgroSaber.git

Entre na pasta:

cd AgroSaber

Abra o arquivo "index.html" no navegador.

«A demonstração frontend não exige execução de servidor Python.»
